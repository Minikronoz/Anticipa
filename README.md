🌟 Anticipa
Anticipa es una solución tecnológica orientada a apoyar a niños con Necesidades Educativas Especiales (NEE) mediante un sistema de anticipación visual que facilita la comprensión de rutinas y actividades diarias.
El proyecto surge a partir de una problemática real presente en entornos educativos y familiares: muchos niños experimentan ansiedad, frustración o desregulación emocional frente a cambios inesperados o dificultades para comprender qué ocurrirá durante el día. Anticipa busca disminuir esa incertidumbre a través de una experiencia visual, estructurada y accesible.
La aplicación permite organizar actividades mediante pictogramas, calendarios visuales y alertas anticipatorias, ayudando a los niños a comprender de manera clara:


📌 Qué actividad realizarán


⏰ Cuándo ocurrirá


🔄 Qué viene después


Además, el sistema entrega herramientas de apoyo para docentes, tutores y familias, permitiendo acompañar de mejor manera el desarrollo de rutinas, hábitos y procesos de autonomía.
🎯 Objetivo del Proyecto
Desarrollar una plataforma accesible e intuitiva que apoye la anticipación de rutinas y actividades en niños con NEE, promoviendo la autonomía, reduciendo la ansiedad y facilitando el acompañamiento pedagógico y familiar.
🚀 Funcionalidades Principales


📅 Calendario visual con pictogramas


🔔 Alertas anticipatorias configurables


⭐ Sistema de refuerzo positivo y recompensas


👨‍🏫 Vinculación entre profesores, tutores y alumnos


📊 Registro de métricas conductuales y emocionales


🔐 Sistema seguro con autenticación por roles


☁️ Integración con Firebase y PostgreSQL


🛠️ Tecnologías Utilizadas


Frontend: Flutter


Backend: FastAPI + Python


Base de Datos: PostgreSQL


Cloud & Servicios: Firebase / Google Cloud


Metodología: Kanban + desarrollo ágil


Control de versiones: GitHub


💡 Impacto Esperado
Anticipa no busca ser únicamente una aplicación, sino una herramienta de apoyo real para mejorar la calidad de vida de niños con NEE y su entorno. El sistema apunta a:


Reducir niveles de ansiedad frente a cambios o rutinas


Facilitar la comprensión temporal y visual


Fortalecer la autonomía progresiva


Mejorar el acompañamiento de docentes y familias


Generar entornos más inclusivos y accesibles
